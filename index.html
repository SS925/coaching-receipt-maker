Save receipts to GitHub

Every receipt you save is stored in your private GitHub repo, so only you can see it and it shows up on all your devices.
  1. On GitHub, create a private repo named coaching-receipts-data (tick “Add a README”).
  2. Go to github.com/settings/personal-access-tokens/new (Settings → Developer settings → Fine-grained tokens → Generate new token).
  3. Name it “Receipt app”. Under Repository access pick Only select repositories → coaching-receipts-data.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, paste it above and tap Connect & save. Do this once on each device.
The key stays only in this browser and can only touch that one receipts repo.
